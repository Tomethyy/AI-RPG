# AI-RPG, Phase 1 (Skeleton)

Hardcoded Story screen: fake turns, fake options, fake dice, generic buttons. No backend, no AI.

Run: `python3 -m http.server 8000`, then open `http://<your-computer-ip>:8000` on the phone (same Wi-Fi).
See `PLAN.md` for the full plan.

Before each deploy run `python3 stamp.py` (stamps build number and time into index.html, style.css and app.js; shown in the More sheet).
